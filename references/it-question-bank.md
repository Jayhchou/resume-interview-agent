# IT 技术岗面试题库（技术面 + 行为面）

> 按岗位分类提供面试题库，供 Step 2 加载。可在此持续扩充已有题目。

## 一、技术面题库（按岗位）

### 后端开发岗
1. 请说说 JVM 内存模型，以及堆和栈的区别？
2. 谈谈你对 HashMap 底层实现原理的理解，JDK 1.8 相比 1.7 有哪些优化？
3. 什么是线程安全？有哪些实现线程安全的方式？
4. 数据库索引为什么用 B+ 树而不是 B 树？什么是索引失效？
5. 谈谈你对事务 ACID 的理解，以及隔离级别有哪些？
6. 什么是缓存穿透、缓存击穿、缓存雪崩？分别如何解决？
7. 谈谈你对微服务架构的理解，服务间如何通信？
8. 你如何排查一次线上接口响应变慢的问题？

### 前端开发岗
1. 说说浏览器从输入 URL 到页面渲染的完整过程？
2. 谈谈你对原型链和闭包的理解？
3. 什么是防抖和节流？分别适用什么场景？
4. 谈谈你对前端工程化和模块化的理解？
5. 虚拟 DOM 是什么？它解决了什么问题？
6. 如何优化前端页面加载性能？
7. 谈谈 HTTP 缓存机制？

### 算法岗
1. 介绍一下你熟悉的一个机器学习模型及其原理？
2. 什么是过拟合？如何缓解？
3. 谈谈你对 Transformer 结构的理解？
4. 如何评估一个模型的性能？常用指标有哪些？
5. 数据不平衡问题如何处理？

## 二、行为面题库（STAR 场景）

1. 请分享一个你最有成就感的项目经历？
2. 讲一次你和团队成员发生分歧，最终如何解决的经历？
3. 描述一次你面临重大压力的经历，你是如何应对的？
4. 讲一个你失败或犯错的经历，你从中学到了什么？
5. 请举例说明你如何快速学习一项新技术并应用到实践中？
6. 描述一次你主动承担责任或推动事情落地的经历？

## 三、追问点（技术题配套）

- "为什么这么设计？"（考察原理理解深度）
- "如果数据量扩大 10 倍，你的方案还成立吗？"（考察边界思考）
- "有没有别的方案？对比一下优缺点？"（考察广度）
- "你在项目里具体怎么用的？踩过什么坑？"（考察实战）
