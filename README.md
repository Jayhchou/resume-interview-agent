# 简历陪练 · 简历诊断与模拟面试训练系统

面向高校毕业生的**简历诊断改写**与**模拟面试训练**系统。WorkBuddy AI 应用开发大赛 · AI 科研教学赛道参赛作品。

系统以**自建 Web 应用**形式交付：前端页面 + 后端服务，发布后获得公网链接，浏览器打开即用，无需注册、无需安装。

> 本仓库为公开仓库。所有文档、截图、演示数据**不含任何个人身份信息**。

---

## 一、解决的核心问题

应届生的简历普遍是自我评价式的空话，缺可验证的证据与岗位匹配度；模拟面试几乎没有低成本的一对一机会，一位就业指导老师对数百名学生，只能做群体讲座。

本系统把「诊断 — 改写 — 演练 — 复盘」做成闭环，让一对一陪练人人可用。两条硬约束贯穿全流程：

- **改写不新增原文没有的事实**——不给数字，给提问。
- **面试只问简历里真实存在的经历**——每题锚定事实编号，可溯源。

---

## 二、六步主链路

```
简历接入与在线编辑 → 五维诊断 → 定向改写 → 事实清单生成
        → 模拟面试 → 结构化复盘 → （二次训练回到诊断）
```

整条链路首尾相接：同一份简历可以反复练，五维分数的变化就是价值证明。

## 五、团队协作

### 5.1 匿名约定（硬性）

仓库为公开仓库，赛事要求提交材料不得出现任何身份信息。以下内容**一律禁止**进入本仓库：

- 真实姓名、学号、院校名称及简称、指导教师姓名
- 手机号、邮箱、微信号、身份证号等联系方式
- 含上述信息的原始简历样本（脱敏后放入，或只放结构化字段）

截图入库前逐张检查：界面头像与昵称、输出中的本地文件路径、简历正文中的姓名与电话。

需要留存真实材料的临时目录，统一放在 `raw/` 或 `private/`——`.gitignore` 已将其排除。

### 5.2 一份文件一个 owner

| 区域 | 内容 | 谁改 |
|---|---|---|
| 前端 | `web-v1/`（`web/` 已冻结，不再改） | 前端组 |
| 后端 | `server/` | 后端组 |
| 知识资产 | `references/` | 按资料专人负责，一份一个 owner |
| 文档 | `docs/` | 各章负责人 |

不交叉修改。`server/prompts/` 与平台运行行为强相关，改动须经队长确认。

### 5.3 提交规范

```
<类型>: <一句话说明>

类型：feat 新增能力 / fix 修正 / docs 文档 / prompt 提示词变更 / chore 杂项
示例：prompt: 简历诊断增加「量化证据缺失」判定项
```
