# 技能目录

每个技能一个子目录，结构固定：

```
skills/
└── <技能名>/
    ├── SKILL.md        职责、触发条件、输入输出契约、执行步骤
    ├── references/     评分细则、维度定义、范例（可选）
    └── scripts/        需要确定性计算时的脚本（可选）
```

## 编写约定

1. **只写方法与约束，不写人设。** 人设属于入口层（见 `../expert-prompt.md`）。
2. **输入输出必须是结构化字段。** 下游技能靠字段衔接，不靠自然语言衔接。
3. **每个技能自带拒答规则。** 例如 `resume-rewrite` 遇到「帮我编一段实习」必须拒绝。
4. **一个技能只做一件事。** 诊断不负责改写。

详细边界见 [`../docs/02-架构设计.md`](../docs/02-架构设计.md) 第三节。
